# 验收清单

## 概览

以下为接手后的验收计划，**不是已通过的测试报告**。按用户约定，测试设计与执行时间需要先对齐。

## 视觉与布局

- [ ] 1440×900、1920×1080 桌面：三栏布局，主内容与消息区可独立滚动。
- [ ] 1024px 窗口：页眉元素不溢出，聊天标题线与页眉底线像素对齐。
- [ ] 390×844、768×1024：导航可用，面板开关始终可达，表单不横向溢出。
- [ ] 早报浅色与晚报深色都保持足够文字对比，浮雕/内凹材质一致。
- [ ] 无顶部样式切换栏、无「你的关注」、无「每日一句」标签、无助手区重复开关。
- [ ] DOMAINS 文案及上方分割线正确。
- [ ] 隐藏/展开助手后中栏宽度与轮播位置正确，草稿未丢失。

## 阅读与聊天

- [ ] 七领域与三种内容类型正确筛选；少数据时不生成虚假头条。
- [ ] 轮播8秒切换，手动/悬停/焦点/隐藏页/减少动态效果状态符合规范。
- [ ] 标题进站内详情，原文开新标签；详情事实/分析区分明确。
- [ ] 返回列表保留约定的筛选与滚动状态。
- [ ] 收藏/取消/空列表/刷新恢复符合当前阶段的持久化承诺。
- [ ] 单行/多行/长文本粘贴/删除/发送后输入框正确缩放；上限144px。
- [ ] Enter发送，Shift+Enter换行，中文输入法选词不误发，空白不发。
- [ ] 切文章后新消息关联新上下文，正在生成的消息保持旧上下文。
- [ ] 失败可重试；重置不会修改长期偏好。

## 活动

- [ ] 默认LA、60 miles、未来日历月，月末与闰年日期不溢出。
- [ ] 地点可编辑；不自动请求精确定位权限。
- [ ] 半径正数；预算非负，空白不限，0表示免费上限。
- [ ] 日期反向被阻止，修正后可提交。
- [ ] 搜索按钮是可访问的放大镜；状态覆盖加载/空/失败/成功。
- [ ] 时间时区、距离单位、票价未知/免费、取消/售罄区分准确。

## 生产数据与调度（接入后验收）

- [ ] 原文链接与摘要内容对应，引用能回溯；无效来源有明确状态。
- [ ] 晚报排除早报已投递事件的转载；新增进展按确认策略处理。
- [ ] America/Los_Angeles 夏令时前后仍在本地09:00/21:00投递。
- [ ] 同一任务重试不会重复发报；失败有可重试记录。
- [ ] 模型密钥不进入前端；采集文本不会被当作控制指令执行。

## 总结

交付报告逐项标明通过、失败、未实施与未执行，并附对应证据。语法通过不能替代视觉、交互与真实服务验收。
