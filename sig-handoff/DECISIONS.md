# 决策记录与待确认事项

## 概览

目的：保留用户已选定设计，避免接手者重新设计；同时明确原型中的偶然行为与功能缺口。

## 已定决策

- 品牌 SIG，助手 sig；曾用 ORBIT、知遇、NEXUS、PULSIG 均非最终名。
- 用户选择克制科技风，浅色早报/深色晚报，表面有浮起质感。
- 左导航固定，DOMAINS 上方分隔；正文独立滚动。
- 头版横向轮播，七领域各一条；深度阅读与来源链接。
- 页眉每日句靠品牌后方并以竖线分隔；早晚切换放页眉。
- 助手可收起，铺满高度；标题边界与页眉对齐；仅页眉保留开关。
- 输入框短小、自适应；近期活动由紧凑表单直接操作。
- 删除视觉预览栏、冗余「你的关注」行和助手重复开关。

## 正式实现前优先确认

1. 技术路线、运行/部署位置与月度服务预算。
2. 新闻/活动数据源、模型提供方及推送渠道。
3. 晚报遇到早报事件的重要新进展：允许带「更新」标记还是完全排除？
4. 首次进入默认最新已发布版本还是按本地时间选版？是否需要历史报刊入口？
5. 精选文章是否可跨期重现？原型当前不按早晚报过滤长文。
6. 长期偏好变更何时直接保存、何时询问？对话/收藏保存多久？
7. 活动人工选择日期的包含范围、未知票价处理和预算是否含税费。

## 已知原型缺口（本包未修改）

| 问题 | 影响与建议 |
| --- | --- |
| 窄屏助手覆盖页眉，内部关闭按钮已按要求删除 | 唯一可见页眉开关可能被遮住；应让页眉开关保持可达，先与用户对齐窄屏方案 |
| ≤600px 左导航个人入口被隐藏 | 稍后阅读/活动可能缺少直接入口；应补窄屏导航方案 |
| 侧栏显隐未主动校准轮播位置 | 宽度变化后可能偏移；建议 ResizeObserver/状态驱动校准 |
| 当前头像只是LK文字 | 不是账户管理或登录入口 |
| 收藏、草稿、搜索条件无持久化 | 刷新丢失；不能承诺保存 |
| 活动表单只有日期，搜索只是toast | 不支持真实地理/时间/预算检索 |
| 首页活动摘要及预设聊天仍写固定LA范围 | 修改表单后其他说明可能不同步，正式版应共用状态 |
| 品牌回全部但保留内容类型；详情返回清零滚动 | 非最终返回导航设计，需确认 |
| 晚报只是另一批演示条目 | 不存在真正事件去重或定时分发 |
| 原型动态模板部分直接插值 | 生产接外部文本时需安全渲染、URL校验 |
| 样式逐轮追加覆盖 | 不按文件前面单条CSS判定最终效果；组件化应整理最终样式 |

## 验证状态

当前代码的若干轮修改通过过 Node 语法检查；并非完整测试套件。用户提供截图并认可设计，但最近自动浏览器连接失败，当前包没有全视口截图或端到端测试结果。Claude 接手应先复核基线，不要宣称本包「已完成全面验收」。

## 总结

设计方向无需重选；需要确认的是生产行为和技术边界。已知缺口透明交接，不以推测填补需求。
