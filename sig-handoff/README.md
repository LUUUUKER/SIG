# SIG 设计与开发交接包

版本：2026-09-29。语言：中文。目标接手工具：Claude Code。

## 概览

SIG 是个人使用的 AI 新闻与活动阅读空间。用户已认可当前「克制科技风、早报浅色、晚报深色、浮雕质感」设计。本包记录设计基线与产品意图，不代表生产系统已完成。

| 文件 | 用途 |
| --- | --- |
| CLAUDE.md | 接手入口、权限边界与协作方式 |
| PRODUCT.md | 产品范围、内容规则、已实现与待开发边界 |
| UI_FLOW.md | 页面结构、阅读/聊天/活动流程与状态变化 |
| DESIGN_SYSTEM.md | 布局、颜色、字体、材质及组件规范 |
| INTERACTIONS.md | 操作与反馈、状态保留、异常场景 |
| IMPLEMENTATION.md | 建议组件拆分、数据对象、调用链与开发顺序 |
| ACCEPTANCE.md | 可执行的视觉与功能验收清单 |
| DECISIONS.md | 已定决策、待确认问题、原型已知缺口 |
| prototype/index.html | 当前设计的独立 HTML 快照，可直接打开 |
| manifest.json | 快照来源和 SHA-256 校验值 |

## 阅读顺序

Claude Code 先读 CLAUDE.md → PRODUCT.md → UI_FLOW.md → DESIGN_SYSTEM.md，再打开 prototype/index.html。开发前结合 DECISIONS.md 与用户确认实施范围、技术方案及调用链。

prototype/index.html 可双击打开；也可在本目录执行 `python3 -m http.server 8765 --bind 127.0.0.1`，访问 `/prototype/index.html`。若端口被占用，更换端口即可。

## 事实与约束

- **已确认**：用户明确要求的产品与视觉决策。
- **原型现状**：从 HTML 读取的实际行为，不等于正式版应照搬的全部行为。
- **建议**：正式版建议处理方式，未经用户确认不算最终需求或技术选型。
- HTML 是视觉参考，不是生产代码模板。它含累积的 CSS 覆盖规则与预设演示数据。
- 最近修改做过脚本语法检查；内置浏览器连接失败，未完成当前版本的完整浏览器视觉/交互验收。不要宣称已全面测试通过。
- 未提供 Figma 文件、生产数据库、密钥、真实接口、真实活动列表或可运行的新闻采集服务。

## 总结

以当前 HTML 和已确认决策保护设计，以交互规范和验收清单指导实现。先对齐方案，再按用户授权逐步开发。
