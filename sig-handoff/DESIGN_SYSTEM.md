# 视觉与组件规范

## 概览

设计基线为 prototype/index.html 的最终层叠结果。以下是关键数值摘录，不是逐条 CSS 清单。不要恢复已废弃的 marble/obsidian 风格选择。

## 布局

| 项目 | 桌面基线 |
| --- | --- |
| 页眉 | 81px 高；左为 SIG 与分隔线后的鼓励句；右为版本/头像/助手开关 |
| 左导航 | 常规 190px；951–1180px 为 150px；1550px 起为 210px |
| 助手 | 常规 345px；951–1180px 为 300px；1550px 起为 385px |
| 助手位置 | fixed，top:0，height:100dvh，右侧贴边 |
| 助手标题 | 与页眉共享高度变量，底线必须对齐 |
| 中间内容 | 剩余宽度，自身滚动；助手隐藏后回收宽度 |
| 主内容边距 | 常规左右36px，较窄25px，宽屏55px；最终效果以快照为准 |
| 窄屏 | ≤950px 助手默认隐藏并作为覆盖面板；≤600px 页眉110px、导航横排 |

页面不要出现顶部方案说明栏。不要增加「你的关注」或重复的晨间大标题占用首屏。DOMAINS 上方 1px 分割线与约22px 内边距；移动横排导航不重复这条分隔。

早报 raised 渐变：#f3f8fc → #e4edf4。晚报：#192a3a → #111e2d。浮起效果使用右下暗影、左上轻高光；输入框和选中槽使用内阴影。背景细网格低透明度，不压过文本。主题颜色随早晚报切换，非单独设置页。

## 字体与形状

主字体 Avenir Next / PingFang SC / Microsoft YaHei / sans-serif。品牌约25px；领域页标题24px；头版标题29px（窄屏25px）；新闻标题约19px；类型切换14px；领域轮播标签13px（移动12px）；文章领域标签12px。正文与辅助信息沿用快照层级，生产态还需检查小字号可读性。

卡片圆角12–16px，输入和小按钮约7–10px。主新闻卡片轻微悬浮反馈，避免大范围运动。放大镜和侧栏开关用线性 SVG；图标按钮必须有可访问名称。

## 组件清单

| 组件 | 视觉/行为规范 |
| --- | --- |
| AppHeader | 品牌、每日句、早晚报、头像、唯一桌面聊天开关 |
| SidebarNavigation | MY EDITION + DOMAINS；选中项浮起 |
| HeadlineCarousel | 横向大卡片、领域切换、计数、前后/暂停控件 |
| ContentTypeTabs | 新闻/精选文章/名人动态；直接接头版下方 |
| ArticleCard | 领域、类型、阅读时长、标题、摘要、来源、收藏、深聊 |
| ArticleDetail | 摘要与 AI 分析分区，明确来源 |
| ActivitySearch | 地点/半径/起止日期/每人预算上限/放大镜，响应式紧凑网格 |
| ChatPanel | 标题只保留头像、sig·阅读伙伴、重置；上下文默认折叠 |
| ChatComposer | 默认26px textarea，上限144px，超过后内部滚动；发送后缩回 |
| Feedback | 简短提示、明确空态、真实错误与重试；生产态另补流式状态 |

## 总结

核心是材质层次与阅读空间。组件化可以调整内部组织，但不能以默认组件库外观替换当前设计。
