# 交互与状态契约

## 概览

本表同时描述现状和正式版建议。未标已确认的异常处理属于实现建议，需纳入方案讨论。

| 操作 | 原型行为 | 正式版建议/验收重点 |
| --- | --- | --- |
| 点品牌 | category=全部，保留当前类型，滚到顶部 | 是否始终回首页新闻待定 |
| 点领域 | 保留当前类型与版本，刷新列表 | 选中高亮；无数据有清楚空态 |
| 切内容类型 | 更新类型并刷新 | 路由/返回状态保持一致 |
| 点文章标题 | 详情替换中栏；助手上下文跟随 | 保留列表筛选与返回滚动位置 |
| 点来源 | 新标签打开参考链接 | 正式版对应准确原文，外链安全属性 |
| 收藏 | 本次会话内切换；稍后阅读立即更新 | 持久化，失败回滚并提示 |
| 早晚切换 | 换主题/演示条目，离开详情 | 详情切换策略需确认，不应无提示丢输入 |
| 隐藏助手 | 桌面释放宽度，不清空消息/草稿 | 保持焦点可达，轮播尺寸变化后不偏移 |
| 重置 | 清空消息，显示新提示 | 明确上下文与草稿保留策略；不清偏好 |
| 发送 | Enter 发送；Shift+Enter 换行；中文输入法组合中不发 | 空白禁发、生成中状态、失败可重试 |
| 对话改偏好 | 仅“只看 AI/GitHub”等关键词示范 | 临时筛选与长期偏好分开，说明影响、可撤销 |
| 活动输入 | 本次页面内保留编辑；日期下界随开始日更新 | 地点不自动请求定位；手动地址用于明确查询 |
| 搜索活动 | 表单校验后 toast；无网络请求 | 校验→加载→结果/空/失败，不伪造命中 |

## 状态建议

- ReadingState：editionId、domain、contentType、articleId、列表滚动位置。
- ChatState：isOpen、draft、messages、requestStatus、发送时冻结的 contextRef。
- ActivityState：draftFilters、submittedFilters、category、results、status、error。
- PreferenceState：长期领域和过滤规则；与当前视图临时状态分开。
- 数据层：收藏、已分发新闻集合、报刊快照；必须可恢复且可去重。

建议助手隐藏后仍允许后台完成答案，重新展开能看到状态；跨页请求须保持原上下文标注。具体会话持久化期限待确认。

## 边界和异常

必须覆盖：内容源不可访问、摘要失败、无合格头版、活动无结果、定位地址无法解析、日期反向、预算为0、票价未知、模型限流/断连、重复提交、推送重试、夏令时转换。

无障碍：页眉开关 aria-expanded 与实际可见性一致，隐藏内容不可键盘访问；焦点可见；轮播暂停；减少动态效果支持；窄屏面板不得遮住唯一关闭入口。后者是当前原型缺口，见 DECISIONS.md。

## 总结

界面切换不应丢失用户输入，任何数据/AI失败必须可见，临时操作不应偷偷变成长期偏好。
